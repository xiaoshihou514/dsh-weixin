# Security policy

Please do not open a public issue for a vulnerability that could expose bot credentials, local files, or command execution.

Send a private report through [GitHub security advisories](https://github.com/xiaoshihou514/dsh-weixin/security/advisories/new). Include the affected version, setup, impact, and a minimal reproduction if you can provide one safely.

The current release line receives security fixes. Reports about unsupported Harness versions or modified iLink endpoints may be closed after the issue is confirmed outside dsh-weixin.

Do not include real Weixin tokens, account ids, chat ids, or session logs in a report.
