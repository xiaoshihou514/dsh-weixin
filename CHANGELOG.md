# Changelog

## 0.1.0

- Added an installable DeepSeek Harness bundle for Weixin iLink.
- Added QR login with private local credential storage and environment-managed token support.
- Added per-chat Harness sessions, restart-safe mappings, duplicate suppression, and iLink cursor persistence.
- Added `/new`, `/stop`, and `/status` commands.
- Added sender and room allowlists, request limits, retryable chunked replies, and a durable outbound queue.
